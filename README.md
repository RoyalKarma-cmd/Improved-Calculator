# Python Advanced Calculator

This is a beginner-friendly calculator project built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Square
- Percentage
- Power
- Cube

## Concepts Used
- Functions
- Loops
- Conditions
- User Input
- Return Statements
- While Loop
- Break Statement

## How It Works
1. User enters two numbers
2. User selects operation
3. Calculator performs operation using functions
4. Program continues until user exits

## Technologies Used
- Python
